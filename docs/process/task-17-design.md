# Task 17 (revised): showcase site on GitHub Pages — NO embedded emulator

## Decision (the author's, made after a licensing finding)
The product calls BASIC ROM floating-point routines at their original addresses. The only open ROM set (Open ROMs) marks most of the routines we use as NOT DONE (sin, cos, atn, exp, log, FCOMP, FACINX, GIVAYF; sqr partial), so the product cannot run on it, and the original Commodore ROMs have unclear redistribution rights. The author therefore chose: **no live emulator**. The Pages site is a static showcase made of recordings of the real program running in VICE, downloads, and clear run-it-yourself instructions. (The original spec said "if possible inside a JavaScript emulator"; this is the documented fallback. Do not build or vendor any emulator, and put no ROM files in the repository.)
