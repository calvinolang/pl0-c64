PL/0 for the Commodore 64

PL/0 with floats and turtle graphics, running on a Commodore 64. Niklaus Wirth's small teaching language from Algorithms + Data Structures = Programs, extended with floating-point numbers, maths functions and a turtle on the C64's 320×200 bitmap screen. One program holds a full-screen editor, the compiler and the interpreter; load it from a disk image, press F1, and your program runs.

Run it yourself

  1. Download the disk image pl0.d64 (the program and the 15 examples) or the bare program pl0.prg.
  2. Install VICE, the Versatile Commodore Emulator, with its C64 ROMs.
  3. Start it: 
    x64sc -autostart pl0.d64
    or, without the examples, x64sc pl0.prg. Loading from the emulated 1541 takes about 80 seconds of emulated time, as on a real C64; VICE normally warps through an autostart, so the wait is much shorter (if it does not, warp mode, Alt+W, makes it quick).

Keys

Keys of the editor
KeyDoes
F1compile and run; an error comes back with the cursor on its line
F2new program
F3open a program or an example from the disk
F5save to the disk
F7help
RUN/STOP (Esc on a PC keyboard in VICE)stop a running program
SPACE after a drawingswitch between the drawing and the text output; any other key returns to the editor

Any emulator that runs the original Commodore 64 ROMs should work, and so should a real C64 with a 1541 drive; VICE (x64sc, 3.7) is the one the program is tested on.

Why no emulator in the browser?

The program calls the floating-point routines of the C64's BASIC ROM, and the only open replacement ROMs do not implement most of them yet, while the original Commodore ROMs cannot be redistributed here with clear rights. So this page shows recordings of the real program and lets you run it in your own emulator, which brings its own ROMs.
